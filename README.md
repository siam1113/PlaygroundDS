# Playground DS

A personal playground for practicing data science and machine learning concepts.

## Contents

- `statistics/` — exercises covering statistical concepts
- `titanic/` — practice using the classic Titanic dataset (train/test CSV files) for classification exercises
- `cwh_ml/` — machine learning exercises and notes
- `Prac/` — general practice files
- `requirements.txt` — Python dependencies used across the exercises

## Purpose

This repository is a sandbox for trying out data science and machine learning techniques on sample datasets, rather than a single cohesive project.
